# 2027-HETC

广州中考艺术特长生资讯与测算页面 V1，面向 2027 届考生使用。

## 使用方式

直接打开 `index.html` 即可使用；也可以将本目录作为静态网站根目录部署。

## 内容口径

- 页面使用 2026 年录取结果、招生计划、控制线和联系方式作为当前参考数据。
- 2027 招生时间线按 2026 年流程推算，仅供提前安排，最终以广州招考和学校公告为准。
- 学校公众号二维码暂不内置，详情页会提示用户在微信中搜索公众号名称并核对认证信息。

## 发布边界

正式发布内容为 `index.html` 和 `assets/`。`preview/`、备份文件和设计工具目录仅用于本地工作，不纳入发布包。
